`createSupabaseProvider` is a request-scoped server factory. It disables persistence and automatic refresh, uses a configured origin and public/anon key, bounds network calls, refuses redirects, disables caching and returns safe identity metadata. Its internal refresh method returns credentials only to the server store. Refresh uses the standard Supabase token endpoint exactly once, then revalidates the access token. Inspection of installed auth-js 2.117.3 found automatic retry in `_refreshAccessToken`; one-shot HTTP refresh avoids reusing a token after an ambiguous rotation response. No custom token issuer is added.
